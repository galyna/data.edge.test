# Enhanced Lovable Prompt: Sports Data Analytics Platform

## Концепция продукта

Создай современную аналитическую платформу для спортивных данных, которая агрегирует информацию из множественных источников (API букмекеров, статистических сервисов, новостных фидов) и предоставляет инструменты для анализа и поиска неэффективности рынка. Платформа объединяет четыре основных источника данных: мультиспортивные фиды, новости, экспертный анализ и киберспорт.

**Философия:** Не просто показывать данные, а помогать пользователям находить value через агрегацию, сравнение источников и продвинутую аналитику. Это аналитический терминал для принятия решений, а не просто информационный сайт.

**Ключевые принципы:**

- Все данные из live APIs (no static data)
- Агрегация из множественных источников с нормализацией
- Аналитика на основе сравнения источников (spread, best source, edge detection)
- SEO оптимизация с structured data для Google
- Data-heavy/analytics-focused дизайн

## Технический стек и требования

### Технологии

- **Frontend:** Next.js 14+ (App Router), React, TypeScript
- **Стилизация:** Tailwind CSS (темная тема по умолчанию)
- **Графики:** Recharts или Chart.js для интерактивных визуализаций
- **Backend:** Node.js API routes для агрегации данных
- **Данные:** Интеграция с множественными API источниками (Sportradar, SportsDataIO, NewsAPI, PandaScore и др.)
- **Архитектура:** SSR для SEO, основной UI — клиентский SPA с live updates

### Критические требования

- ✅ **No static data** — каждый stat, line и feed обновляется из live APIs
- ✅ **SEO optimized** — Next.js SSR + schema markup для событий, игроков, коэффициентов
- ✅ **Structured data** — JSON-LD для Google (events, players, odds, predictions)
- ✅ **Auto-refresh** — обновление данных каждые 5-10 секунд для live events
- ✅ **Multi-source aggregation** — нормализация данных из разных источников

## 1. Comprehensive Multi-Sport Data Feeds (Мультиспортивные фиды)

### Multi-Source Odds Comparison Table (Главная секция)

**Расположение:** Основная область, 3-4 колонки на десктопе

**Компонент:** Таблица агрегированных данных из множественных источников

**Структура таблицы:**

```
Матч | Aggregated Odds | Spread | Best Source | Value % | Status
```

**Колонки:**

- **Матч:** Логотипы команд, названия, время начала
- **Aggregated Odds:** Медиана/среднее из всех источников (Home/Draw/Away)
- **Spread:** Разброс между мин/макс (зеленый = низкий spread, красный = высокий = возможная неэффективность)
- **Best Source:** Источник с лучшим коэффициентом для каждого исхода
- **Value %:** Расчет edge на основе aggregated vs model probability (зеленый акцент)
- **Status:** Live/Scheduled/Finished индикатор

**Визуализация:**

- Строки с hover эффектом (подсветка `#2a2a2a`)
- Цветовое кодирование:
  - Зеленый текст для высокого value (>5%)
  - Желтый для среднего value (2-5%)
  - Серый для низкого value (<2%)
- Автообновление каждые 5-10 секунд с fade-in анимацией на измененных ячейках
- Клик по строке открывает детальную панель матча

**Детальная панель матча:**

- Сравнительная таблица всех источников с коэффициентами
- График spread во времени
- История агрегации и аномалий
- Метрики качества данных (latency, freshness по каждому источнику)
- Live score и статистика (если матч идет)

### Live Scores Dashboard

**Компоненты:**

- Крупные карточки матчей с четким разделением команд

## 3. Expert Analysis & Match Tips (Экспертный анализ)

### Value Radar (на основе агрегации)

**Компонент:** Карточка "Value Signals from Aggregation"

**Структура:**

- Список матчей с высоким value, обнаруженным через сравнение источников
- Формат:
  ```
  🟢 Arsenal vs Chelsea
     Avg: 2.15 | Best: 2.25 | Edge: +4.7%
     Sources: 5 | Spread: Low
  ```

**Метрики:**

- **Avg** = средний коэффициент из всех источников
- **Best** = лучший доступный коэффициент
- **Edge** = разница между best и avg (value в процентах) - зеленый акцент
- **Sources** = количество активных источников
- **Spread** = качество агрегации (Low/Medium/High)

**Визуализация:**

- Зеленый индикатор для высокого edge
- Цветовое кодирование по уровню value
- Клик открывает детальную информацию о матче

### Экспертные прогнозы

**Компоненты:**

- Карточки экспертов с аватаром и именем
- Рейтинг/статистика точности эксперта (процент, звезды, числовой рейтинг)
- Прогноз на исход матча крупным шрифтом
- Обоснование прогноза в виде текстового блока
- Ключевые факторы в виде списка или тегов
- История успешности в виде мини-графика или таблицы

**Визуализация:**

- Цветовое кодирование по уровню уверенности
- Индикаторы точности (зеленый для высокого, желтый для среднего, красный для низкого)
- Аватары экспертов с рамкой, цвет которой зависит от рейтинга

### Алгоритмические прогнозы

**Компоненты:**

- Карточка с названием модели/алгоритма

**Компонент:** Карточка "Data Sources"

**Структура:**

**Компонент:** Карточка "Aggregation Anomalies"

**Структура:**

- Лента аномалий, обнаруженных при агрегации:

**Типы аномалий:**

- Высокий spread между источниками
- Отклонение источника от агрегированной медианы
- Возможная неэффективность рынка (value opportunity)

## Функциональность MVP

### Data Aggregation Engine

**Требования:**

- Интеграция с 3-5+ источниками данных (симуляция в MVP, реальные API в продакшене)
- Каждый источник:
  - Разные коэффициенты (реалистичный разброс ±0.05–0.15)
  - Разная задержка обновления (3-15 секунд)
  - Разная структура данных (требуется нормализация)
- **Normalizer** унифицирует данные в единый формат

**Структура нормализованных данных:**

```typescript
{
  source: "Source A",
  odds: { home: 2.15, draw: 3.40, away: 3.20 },
  timestamp: "2024-01-15T14:32:00Z",
  latency: 120
}
```

### Analytics на основе агрегации

**Метрики:**

- **Aggregated Odds** = медиана всех источников (устойчива к выбросам)
- **Spread Calculation** = (max - min) / avg \* 100 (процент разброса)
- **Value Detection:**
  - Сравнение агрегированной медианы с model probability
  - Выявление источников с аномальными коэффициентами
  - Расчёт edge = (best_odds - avg_odds) / avg_odds \* 100
- **Line Movement Tracking** = агрегированная линия + отдельные линии источников

### Автообновление

**Механизм:**

- Все источники обновляются независимо (разные интервалы)
- Агрегированные данные пересчитываются при каждом обновлении любого источника
- Визуальная индикация:
  - Краткая анимация fade на обновлённых ячейках
  - Счетчик активных источников в header
  - Таймер "Last sync: Xs ago"

### Интерактивность

**Фильтры:**

- По лигам (кнопки в header)
- По видам спорта
- По статусу матчей (live/scheduled/finished)
- По уровню value

**Детальная панель матча:**

- Детальное сравнение всех источников (таблица)
- График spread во времени
- История агрегации и аномалий
- Метрики качества данных (latency, freshness по каждому источнику)
- Live score и статистика
- Прогнозы экспертов и алгоритмов
- Новости о матче

## Что НЕ включать

- ❌ Экспертные прогнозы без указания источника и статистики точности
- ❌ Реклама или баннеры
- ❌ Большие блоки текста без данных
- ❌ Скруглённые углы (минимальные скругления 2-4px)
- ❌ Яркие декоративные цвета (только функциональный зеленый для value)
- ❌ Показ данных только из одного источника без агрегации
- ❌ Статические данные (все должно обновляться из live APIs)
- ❌ Прогнозы без обоснования и метрик точности

## Критерии успеха прототипа

1. ✅ Видно агрегацию из множественных источников

3. ✅ Выглядит как аналитический терминал, а не сайт букмекера

6. ✅ Live-обновления работают плавно
7. ✅ Понятны метрики качества агрегации (latency, freshness, spread)
8. ✅ Все данные из live APIs (no static data)
9. ✅ SEO оптимизация с structured data
10. ✅ Четыре сущности данных интегрированы и работают вместе

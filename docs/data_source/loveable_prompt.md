# Промт для Loveable: UI для спортивной платформы с данными

## Общее описание проекта

Создай современный UI для комплексной платформы спортивных новостей и прогнозов. Платформа должна отображать данные из четырех основных источников: мультиспортивные фиды данных, спортивные новости, экспертный анализ и советы, киберспорт и нишевые виды спорта.

**Стиль дизайна:** Data-heavy/analytics-focused с современными акцентами. Интерфейс должен быть информационно насыщенным, но при этом чистым и читаемым. Используй темную или светлую тему с акцентами для важных данных. Графики и визуализации должны быть интерактивными и понятными.

**Цветовая палитра:** Современная палитра с акцентами для live-данных (яркие цвета для активных матчей), нейтральные тона для фона, контрастные цвета для статистики и графиков.

---

## 1. Comprehensive Multi-Sport Data Feeds (Мультиспортивные фиды данных)

### Live Scores Dashboard (Табло с live scores)

Создай главный компонент для отображения live scores в реальном времени:

**Визуальные элементы:**
- Крупные карточки матчей с четким разделением команд
- Логотипы команд слева и справа от счета
- Текущий счет выделен крупным жирным шрифтом в центре
- Таймер матча с индикатором статуса (live - пульсирующий красный/зеленый индикатор, finished - серый, scheduled - синий)
- Названия команд под логотипами
- Период/тайм/сет отображается над счетом
- Индикатор обновления данных (анимированная точка или иконка синхронизации)

**Интерактивность:**
- Клик по карточке матча открывает детальную страницу
- Hover эффект с легким подъемом карточки и тенью
- Автоматическое обновление счетов без перезагрузки (визуальная анимация изменения чисел)

**Расположение:**
- Сетка карточек матчей (2-3 колонки на десктопе, 1 колонка на мобильном)
- Фильтры сверху: вид спорта, лига, статус матча
- Поисковая строка для быстрого поиска команд

### Статистические блоки

**Компоненты:**
- Сравнительные графики для основных метрик (владение мячом, удары, передачи)
- Круговые диаграммы для процентных показателей
- Таблицы с расширенной статистикой (сортируемые колонки)
- Мини-графики трендов по периодам матча
- Прогресс-бары для визуализации метрик

**Визуализация:**
- Используй цветовое кодирование (команда 1 - один цвет, команда 2 - другой)
- Интерактивные tooltips при наведении на элементы графика
- Возможность переключения между разными метриками
- Адаптивные графики, которые масштабируются под размер экрана

### Расписание матчей (Schedule)

**Компоненты:**
- Календарный вид с выделением дней с матчами
- Список предстоящих матчей с датами и временем
- Фильтры: вид спорта, лига, дата, важность события
- Чипы/бейджи для статусов (upcoming, live, finished)
- Иконки видов спорта для быстрой идентификации

**Интерактивность:**
- Клик по дате в календаре фильтрует матчи
- Выбор нескольких фильтров одновременно
- Сохранение избранных фильтров
- Переключение между календарным и списковым видом

### Коэффициенты и Odds

**Компоненты:**
- Таблица коэффициентов с названиями букмекеров
- Визуализация изменений коэффициентов (стрелки вверх/вниз, цветовое кодирование)
- Индикаторы фаворитов (звездочки или бейджи)
- Рекомендуемые ставки выделены цветом или иконкой
- График изменения коэффициентов во времени

**Визуализация:**
- Зеленый/красный для повышения/понижения коэффициентов
- Жирный шрифт для рекомендуемых ставок
- Сравнительная таблица с лучшими коэффициентами выделена

### Информация о командах и игроках

**Компоненты:**
- Карточки команд с логотипом, названием, текущей формой
- Таблицы составов с фото игроков
- Статистика игроков в виде карточек или таблиц
- История встреч в виде временной шкалы или таблицы
- Индикаторы травм и дисквалификаций (красные/желтые маркеры)

## 2. Sports News Integration (Интеграция спортивных новостей)

### Новостная лента

**Компоненты:**
- Карточки новостей с изображением-превью слева или сверху
- Заголовок статьи крупным шрифтом
- Краткое описание/аннотация под заголовком
- Метаинформация: источник, автор, дата публикации, категория
- Теги/чипы для категорий (NBA, футбол, теннис)
- Индикатор важности (для breaking news - красный бейдж)

**Расположение:**
- Сетка карточек (2-3 колонки на десктопе)
- Возможность переключения между сеткой и списком
- Бесконечная прокрутка или пагинация
- Сортировка: по дате, популярности, релевантности

**Интерактивность:**
- Hover эффект с увеличением изображения
- Клик открывает полную статью или внешний источник
- Фильтры по видам спорта, источникам, датам
- Поиск по ключевым словам

### Превью матчей (Match Previews)

**Компоненты:**
- Специальные карточки превью с информацией о предстоящем матче
- Логотипы команд и дата/время матча
- Анализ формы команд (последние результаты в виде мини-индикаторов)
- Ключевые факторы матча в виде списка или карточек
- История встреч в компактном виде
- Прогнозы и ожидания выделены отдельным блоком

**Визуализация:**
- Связь с расписанием матчей (клик ведет к странице матча)
- Графики формы команд
- Выделение важных факторов цветом или иконками

### Обзоры матчей (Match Recaps)

**Компоненты:**
- Итоговый счет крупным шрифтом
- Ключевые моменты матча в виде временной шкалы
- Статистика матча в компактных графиках
- Видео-хайлайты (если доступны) в виде превью с play-кнопкой
- Мнения экспертов в виде цитат или карточек

**Визуализация:**
- Временная шкала с точками ключевых событий
- Интерактивные элементы для просмотра деталей события
- Связь с live scores (если матч только что завершился)

### Обновления о игроках

**Компоненты:**
- Карточки новостей с фото игрока
- Тип новости (травма, трансфер, достижение) отмечен иконкой и цветом
- Статистика выступлений в виде мини-графиков
- Связь с профилем игрока

## 3. Expert Analysis & Match Tips (Экспертный анализ и советы)

### Экспертные прогнозы

**Компоненты:**
- Карточки экспертов с аватаром и именем
- Рейтинг/статистика точности эксперта (процент, звезды, или числовой рейтинг)
- Прогноз на исход матча крупным шрифтом
- Обоснование прогноза в виде текстового блока
- Ключевые факторы в виде списка или тегов
- История успешности в виде мини-графика или таблицы

**Визуализация:**
- Цветовое кодирование по уровню уверенности
- Индикаторы точности (зеленый для высокого, желтый для среднего, красный для низкого)
- Аватары экспертов с рамкой, цвет которой зависит от рейтинга

### Алгоритмические прогнозы

**Компоненты:**
- Карточка с названием модели/алгоритма
- Вероятность исхода в виде крупного процента и круговой диаграммы
- Прогнозируемый счет выделен отдельно
- Уровень уверенности модели (прогресс-бар или индикатор)
- Список факторов, учтенных моделью
- Интерактивные графики вероятностей

**Визуализация:**
- Круговые диаграммы для вероятностей исходов
- Градиенты для визуализации уверенности
- Интерактивные элементы для детализации факторов

### Советы по ставкам (Betting Tips)

**Компоненты:**
- Выделенные карточки с рекомендуемой ставкой
- Тип ставки и исход крупным шрифтом
- Коэффициент и потенциальный выигрыш
- Обоснование совета
- Уровень уверенности (1-5 звезд или процент)
- Источник совета (эксперт/алгоритм/консенсус) отмечен бейджем
- Статистика успешности подобных советов

**Визуализация:**
- Цветовое выделение по уровню уверенности (зеленый - высокий, желтый - средний)
- Иконки для типов ставок
- Выделение лучших советов специальным бейджем или рамкой

### Консенсусные прогнозы

**Компоненты:**
- Сводная карточка с мнениями нескольких экспертов
- Процент экспертов, поддерживающих каждый исход (столбчатая диаграмма)
- Средний прогнозируемый счет
- Индикатор согласованности мнений (высокая/средняя/низкая)
- Визуализация распределения прогнозов (гистограмма или scatter plot)

**Визуализация:**
- Столбчатые диаграммы для процентного распределения
- Индикаторы согласованности (чем выше согласованность, тем ярче цвет)

### Аналитические инсайты

**Компоненты:**
- Интерактивные графики статистических трендов
- Сравнительные таблицы команд
- Карточки с ключевыми факторами, влияющими на исход
- Временные графики исторических паттернов
- Интерактивные элементы для детального анализа

**Визуализация:**
- Линейные графики для трендов
- Heatmaps для сравнения команд
- Интерактивные tooltips с детальной информацией

## 4. E-sports & Niche Sports Coverage (Киберспорт и нишевые виды спорта)

### Киберспортивные матчи

**Компоненты:**
- Карточки матчей с логотипом игры (LoL, CS:GO, Dota 2, Valorant)
- Логотипы команд и названия
- Текущий счет и статус матча
- Таймер с этапом матча (раунд, карта, период)
- Турнир и лига отмечены бейджами
- Специфичные индикаторы для каждой игры

**Визуализация:**
- Иконки игр для быстрой идентификации
- Цветовое кодирование по играм
- Адаптация под специфику каждой игры (разные метрики для разных игр)

### Детальная статистика киберспорта

**Компоненты:**
- Таблицы K/D/A для MOBA/FPS игр
- Индикаторы захватов целей и контроля карты
- Экономика команды (для CS:GO/Valorant) в виде графиков
- Статистика по картам/раундам в виде временной шкалы
- Карточки производительности отдельных игроков
- Сравнительные метрики команд в виде графиков

**Визуализация:**
- Специализированные графики для каждой игры
- Интерактивные элементы для переключения между метриками
- Мини-карты для визуализации контроля территории (где применимо)

### Нишевые виды спорта

**Компоненты:**
- Карточки событий с названием вида спорта
- Информация о турнире/соревновании
- Участники/команды
- Расписание и результаты
- Специфичная статистика в адаптированном формате
- Рейтинги и таблицы

**Визуализация:**
- Иконки видов спорта
- Адаптивные компоненты под специфику каждого вида спорта

### Турнирные сетки и таблицы

**Компоненты:**
- Визуальные брекеты турниров
- Групповые стадии в виде таблиц
- Таблицы лиг с сортировкой
- История выступлений в виде временной шкалы
- Прогресс команд в турнире визуализирован

**Визуализация:**
- Интерактивные брекеты с возможностью клика по матчам
- Цветовое кодирование для статусов команд (прошли дальше, выбыли)
- Анимации при обновлении результатов

## Общие требования к UI

### Навигация

**Главное меню:**
- Логотип платформы слева
- Основные разделы: Live Scores, News, Predictions, E-sports, Schedule
- Иконка уведомлений
- Профиль пользователя/настройки

**Боковая панель (опционально):**
- Быстрый доступ к избранным командам/лигам
- Фильтры по видам спорта
- Настройки отображения

### Адаптивность

- Мобильная версия: одна колонка, компактные карточки, выдвижное меню
- Планшет: 2 колонки для карточек
- Десктоп: 3+ колонки, расширенные возможности

### Интерактивность

- Плавные анимации при переходах
- Loading states для загрузки данных
- Empty states когда данных нет
- Error states для ошибок загрузки
- Skeleton loaders для контента в процессе загрузки

### Персонализация

- Настройки темы (светлая/темная)
- Выбор приоритетных видов спорта
- Сохранение избранных команд/лиг
- Настройка уведомлений

### Производительность

- Ленивая загрузка изображений
- Виртуализация длинных списков
- Оптимизация графиков и визуализаций
- Кэширование часто используемых данных

## Технические детали для реализации

### Компоненты для создания

1. **LiveScoreCard** - карточка live матча
2. **StatsChart** - компонент для графиков статистики
3. **MatchSchedule** - расписание матчей
4. **OddsTable** - таблица коэффициентов
5. **NewsCard** - карточка новости
6. **MatchPreview** - превью матча
7. **ExpertPrediction** - карточка экспертного прогноза
8. **AlgorithmPrediction** - карточка алгоритмического прогноза
9. **BettingTip** - карточка совета по ставке
10. **EsportsMatchCard** - карточка киберспортивного матча
11. **TournamentBracket** - турнирная сетка
12. **FilterBar** - панель фильтров
13. **SearchBar** - поисковая строка

### Анимации

- Пульсация для live индикаторов
- Плавное появление карточек при загрузке
- Анимация изменения чисел в счетах
- Hover эффекты с подъемом и тенью
- Плавные переходы между состояниями

### Цветовая схема

**Основные цвета:**
- Live индикатор: #FF4444 (красный) или #00FF00 (зеленый)
- Акцент: #0066FF (синий) или #FF6600 (оранжевый)
- Успех: #00CC66 (зеленый)
- Предупреждение: #FFAA00 (желтый)
- Фон: #F5F5F5 (светлый) или #1A1A1A (темный)
- Текст: #333333 (светлый) или #FFFFFF (темный)

**Градиенты:**
- Используй градиенты для акцентов и важных элементов
- Градиенты для фонов карточек (опционально)

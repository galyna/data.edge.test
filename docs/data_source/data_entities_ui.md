# Сущности источников данных и их UI-компоненты

Документ описывает четыре основные сущности источников данных платформы и определяет, какие UI-компоненты должны быть доступны для маркировки (labelable) и какую функциональность они должны предоставлять.

## 1. Comprehensive Multi-Sport Data Feeds (Мультиспортивные фиды данных)

### Описание сущности

Источник данных, предоставляющий live scores, статистику, расписания и коэффициенты по множеству видов спорта.

### Labelable UI-компоненты

**Табло с live scores**

- Отображение текущего счета матча в реальном времени
- Названия команд/участников
- Таймер/время матча (период, тайм, сет)
- Статус матча (live, finished, scheduled, postponed)
- Логотипы команд
- Индикатор обновления данных (live indicator)

**Статистические блоки**

- Основные показатели матча (голы, очки, владение мячом, удары)
- Детальная статистика по периодам/таймам/сетам
- Сравнительные графики и диаграммы
- Таблицы с расширенной статистикой
- Процентные показатели и метрики

**Расписание матчей (Schedule)**

- Календарь событий
- Список предстоящих матчей с датами и временем
- Фильтры по видам спорта, лигам, датам
- Информация о турнирах и соревнованиях
- Статусы матчей (upcoming, live, finished)

**Коэффициенты и odds**

- Текущие коэффициенты на исходы матча
- Изменения коэффициентов в реальном времени
- Сравнение коэффициентов от разных букмекеров
- Рекомендуемые ставки на основе коэффициентов
- Индикаторы фаворитов и аутсайдеров

**Информация о командах и игроках**

- Составы команд
- Статистика игроков
- История встреч между командами
- Текущая форма команд
- Травмы и дисквалификации

### Функциональность

**Обновление в реальном времени**

- Автоматическое обновление счетов без перезагрузки страницы
- Push-уведомления о важных событиях в матче
- Индикация задержки данных

**Фильтрация и поиск**

- Поиск по командам, лигам, видам спорта
- Фильтры по датам, статусам, важности событий
- Сохранение избранных команд/лиг

**Детализация**

- Переход к детальной странице матча
- Развертывание дополнительной статистики
- История изменений счета и ключевых событий

**Персонализация**

- Настройка отображаемых видов спорта
- Выбор приоритетных лиг и команд
- Настройка формата отображения данных

## 2. Sports News Integration (Интеграция спортивных новостей)

### Описание сущности

Источник новостного контента: превью матчей, обзоры, обновления о игроках, агрегированные заголовки.

### Labelable UI-компоненты

**Заголовки новостей**

- Заголовок статьи
- Краткое описание/аннотация
- Источник новости (издание, автор)
- Дата и время публикации
- Категория/тег (NBA, футбол, теннис и т.д.)
- Изображение-превью

**Карточки новостей**

- Полная карточка статьи с превью
- Связанные матчи/события
- Теги и категории
- Индикатор важности/приоритета
- Количество просмотров/комментариев

**Превью матчей (Match Previews)**

- Информация о предстоящем матче
- Анализ формы команд
- Прогнозы и ожидания
- Ключевые факторы матча
- История встреч

**Обзоры матчей (Match Recaps)**

- Итоговый счет и результат
- Ключевые моменты матча
- Статистика матча
- Видео-хайлайты (если доступны)
- Мнения экспертов о матче

**Обновления о игроках**

- Новости о травмах
- Трансферы и переходы
- Личные достижения
- Интервью и заявления
- Статистика выступлений

**Агрегированные ленты новостей**

- Список последних новостей
- Группировка по видам спорта
- Группировка по важности
- Трендовые темы
- Рекомендуемые статьи

### Функциональность

**Агрегация и фильтрация**

- Автоматический сбор новостей из множества источников
- Фильтрация по релевантности и качеству
- Группировка дублирующихся новостей
- Приоритизация важных событий

**Контекстуальная связь**

- Автоматическая привязка новостей к соответствующим матчам
- Связь новостей о игроках с их профилями
- Связь превью с расписанием матчей
- Связь обзоров с завершенными матчами

**Персонализация контента**

- Рекомендации на основе интересов пользователя
- Настройка источников новостей
- Фильтры по видам спорта и лигам
- Уведомления о важных новостях

**Отображение и навигация**

- Бесконечная прокрутка или пагинация
- Сортировка по дате, популярности, релевантности
- Поиск по ключевым словам
- Переход к полной статье или внешнему источнику

## 3. Expert Analysis & Match Tips (Экспертный анализ и советы по матчам)

### Описание сущности

Источник экспертных мнений, алгоритмических прогнозов и инсайтов для ставок.

### Labelable UI-компоненты

**Экспертные прогнозы**

- Имя эксперта и его рейтинг/статистика точности
- Прогноз на исход матча
- Обоснование прогноза (текстовое описание)
- Ключевые факторы, влияющие на прогноз
- История успешности эксперта
- Аватар/фото эксперта

**Алгоритмические прогнозы**

- Название модели/алгоритма
- Вероятность исхода (процент)
- Прогнозируемый счет
- Уровень уверенности модели
- Факторы, учтенные моделью
- Визуализация вероятностей (графики, диаграммы)

**Советы по ставкам (Betting Tips)**

- Рекомендуемая ставка (тип и исход)
- Коэффициент и потенциальный выигрыш
- Обоснование совета
- Уровень уверенности (1-5 звезд или процент)
- Источник совета (эксперт/алгоритм/консенсус)
- Статистика успешности подобных советов

**Консенсусные прогнозы**

- Сводка мнений нескольких экспертов
- Процент экспертов, поддерживающих каждый исход
- Средний прогнозируемый счет
- Индикатор согласованности мнений
- Визуализация распределения прогнозов

**Аналитические инсайты**

- Ключевые статистические тренды
- Сравнительный анализ команд
- Факторы, влияющие на исход
- Исторические паттерны
- Интерактивные графики и диаграммы

**Сигналы и рекомендации**

- Индикаторы выгодных ставок
- Предупреждения о рисках
- Рекомендации по стратегии
- Оптимальное время для ставки
- Изменения в рекомендациях в реальном времени

### Функциональность

**Гибридный подход**

- Комбинирование экспертных мнений и алгоритмических прогнозов
- Взвешивание источников по их точности
- Отображение различных точек зрения на один матч

**Прозрачность источников**

- Четкое указание источника каждого совета
- Статистика точности для каждого эксперта/модели
- История предыдущих прогнозов
- Рейтинги и репутация источников

**Контекстуальная интеграция**

- Привязка прогнозов к страницам матчей
- Связь с live scores и статистикой
- Обновление прогнозов на основе текущих событий
- Сравнение прогнозов с фактическими результатами

**Персонализация**

- Настройка предпочтений по типам советов
- Выбор доверенных экспертов
- Фильтрация по уровню уверенности
- Уведомления о новых прогнозах для избранных матчей

**Валидация и обратная связь**

- Отслеживание точности прогнозов
- Система рейтингов для экспертов
- Обратная связь от пользователей
- Автоматическая корректировка весов источников

## 4. E-sports & Niche Sports Coverage (Киберспорт и нишевые виды спорта)

### Описание сущности

Специализированные данные для киберспорта и менее популярных видов спорта.

### Labelable UI-компоненты

**Киберспортивные матчи**

- Название игры (LoL, CS:GO, Dota 2, Valorant и т.д.)
- Названия команд/игроков
- Текущий счет и статус матча
- Таймер и этап матча (раунд, карта, период)
- Логотипы команд и игры
- Турнир и лига

**Детальная статистика киберспорта**

- K/D/A (убийства/смерти/ассисты) для MOBA/FPS
- Захваты целей и контроль карты
- Экономика команды (для CS:GO/Valorant)
- Статистика по картам/раундам
- Производительность отдельных игроков
- Сравнительные метрики команд

**Нишевые виды спорта**

- Название вида спорта
- Турнир/соревнование
- Участники/команды
- Расписание и результаты
- Специфичная статистика для вида спорта
- Рейтинги и таблицы

**Коэффициенты для киберспорта**

- Odds на исходы матчей
- Специфичные рынки (первая карта, общий счет карт)
- Live-коэффициенты во время матча
- Сравнение букмекеров
- Рекомендации по ставкам

**Новости и обновления**

- Новости о турнирах и командах
- Трансферы игроков
- Обновления игр и мета-изменения
- Интервью с игроками и тренерами
- Аналитика и разборы матчей

**Турнирные сетки и таблицы**

- Брекеты турниров
- Групповые стадии
- Таблицы лиг
- История выступлений
- Прогресс команд в турнире

### Функциональность

**Специализированная обработка данных**

- Адаптация под специфику каждой игры
- Извлечение данных из стримов в реальном времени
- Обработка быстрых обновлений (киберспорт очень динамичен)
- Корректная интерпретация игровых метрик

**Гибкая архитектура**

- Возможность добавления новых игр/видов спорта
- Настраиваемые метрики для разных дисциплин
- Модульная система для различных источников данных
- Масштабируемость под растущее количество событий

**Интеграция с основными фидами**

- Единообразное отображение с традиционными видами спорта
- Общие компоненты UI с адаптацией под специфику
- Единая система фильтрации и поиска
- Консистентный пользовательский опыт

**Персонализация**

- Выбор предпочитаемых игр/видов спорта
- Настройка отображаемых метрик
- Уведомления о важных событиях
- Избранные команды и игроки

**Образовательный контент**

- Объяснение специфичных терминов и метрик
- Гайды по пониманию статистики
- Контекстная помощь для новых пользователей
- Сравнение с традиционными видами спорта

## Общие требования к labelable компонентам

Все описанные UI-компоненты должны поддерживать:

**Идентификацию и маркировку**

- Уникальные идентификаторы для каждого компонента
- Возможность программного доступа к данным компонента
- Семантическая разметка для доступности
- Метаданные о типе и источнике данных

**Интерактивность**

- Реакция на действия пользователя
- Состояния (hover, active, selected)
- Анимации и переходы
- Обратная связь при взаимодействии

**Адаптивность**

- Корректное отображение на разных устройствах
- Оптимизация для мобильных и десктопных экранов
- Масштабируемость контента
- Производительность при больших объемах данных

**Доступность**

- Поддержка скринридеров
- Клавиатурная навигация
- Контрастность и читаемость
- Альтернативные тексты для изображений

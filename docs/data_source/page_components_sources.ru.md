# Маппинг источников данных для компонентов главной страницы

## Быстрая справка: Названия компонентов и источники

| Код компонента | Заголовок на UI | Платный источник | Бесплатный источник |
|----------------|-----------------|------------------|---------------------|
| `UnifiedSportsFeed` | **UNIFIED SPORTS FEED** (Единая спортивная лента) | SportsDataIO ($400-1000/мес) | API-Sports (free tier) / TheSportsDB |
| `MultiSourceComparison` | **ANALYST COMPARISON** (Сравнение аналитиков) | SportsDataIO + STATSCORE TipsterAPI ($700-1800/мес) | TheSportsDB + The Odds API |
| `OddsAggregator` | **ODDS** (Коэффициенты) | OddsJam / SportsDataIO ($50-400/мес) | The Odds API (free tier) |
| `ValueRadar` | **VALUE SIGNALS** (Ценные сигналы) | STATSCORE TipsterAPI ($300-800/мес) | DIY calculation (собственный расчет) |

**Примечание:** "Код компонента" — имя React-компонента, "Заголовок на UI" — что видит пользователь на экране.

## Расшифровка компонентов

### 1. UNIFIED SPORTS FEED (Единая спортивная лента)

**Расположение:** Левая колонка, верхняя секция  
**Назначение:** Отображение live-матчей, счетов, расписаний по всем видам спорта

**Что нужно от источника:**
- Live-счета и статус матча
- Названия команд/игроков и логотипы
- Расписание матчей (дата, время)
- Информация о лигах/турнирах
- Классификация по видам спорта
- Real-time обновления (каждые 5-10 сек для live-матчей)

**Платный вариант:** SportsDataIO ($400-1000/мес)
- Real-time scores для NBA, NFL, NHL, MLB, Soccer, Tennis
- Расписания и результаты
- Метаданные команд и игроков
- Live-обновления через webhooks
- Исторические данные (15+ лет)
- Высокие лимиты запросов (10,000+ req/день)

**Бесплатный вариант:** TheSportsDB + API-Sports (free tier)
- Расписания и прошлые результаты
- Логотипы команд и метаданные
- Базовые live scores (ограниченное покрытие)
- ⚠️ Лимит: ~100 req/час (TheSportsDB), 100 req/день (API-Sports free)

---

### 2. ANALYST COMPARISON (Сравнение аналитиков)

**Расположение:** Левая колонка, нижняя секция  
**Назначение:** Сравнение данных матча от разных источников, консенсус и расхождения

**Что нужно от источника:**
- Данные матча от 2+ источников
- Коэффициенты/прогнозы от разных провайдеров
- Статистика команд и форма
- История личных встреч
- Экспертные мнения/прогнозы
- Уровни уверенности

**Платный вариант:** SportsDataIO + STATSCORE TipsterAPI ($700-1800/мес)
- Live-данные матча и статистика
- Встроенный движок прогнозов BAKER
- Вероятности победы и рекомендуемые ставки
- Pre-game и live betting insights от TipsterAPI
- Математические модели (10+ видов спорта, 100+ рынков)

**Бесплатный вариант:** TheSportsDB + The Odds API
- Исторические данные матчей
- Статистика команд и форма
- Коэффициенты от нескольких букмекеров
- ⚠️ Лимит: 500 req/месяц (Odds API) = ~16 req/день
- ❌ Нет алгоритмических прогнозов (нужен собственный расчет)

---

### 3. ODDS (Коэффициенты)

**Расположение:** Правая колонка, верхняя секция  
**Назначение:** Отображение и сравнение коэффициентов от разных букмекеров

**Что нужно от источника:**
- Real-time коэффициенты от множества букмекеров
- Разные типы ставок (moneyline, spread, totals и др.)
- Движение линий во времени
- Выделение лучших коэффициентов
- Арбитражные возможности
- Открывающие vs текущие линии

**Платный вариант:** OddsJam / SportsDataIO Odds Feed ($49-299/мес)
- Коэффициенты от 50+ букмекеров
- Real-time обновления (30-60 сек)
- Исторические данные коэффициентов
- Отслеживание движения линий
- API и webhooks
- Расчет подразумеваемых вероятностей

**Бесплатный вариант:** The Odds API (free tier)
- Коэффициенты от 15-20 букмекеров
- Несколько типов ставок
- История до 3 дней
- ⚠️ Лимит: 500 req/месяц = ~16 req/день
- ❌ Нет отслеживания движения линий
- ❌ Только базовое покрытие букмекеров

---

### 4. VALUE SIGNALS (Ценные сигналы)

**Расположение:** Правая колонка, нижняя секция  
**Назначение:** Отображение ценных сигналов для ставок, алертов и рекомендаций

**Что нужно от источника:**
- Алгоритмические прогнозы с вероятностями
- Рыночные коэффициенты для сравнения
- Расчет ценности (прогноз vs коэффициенты)
- Оценки уверенности
- Рекомендации по ставкам
- Отслеживание исторической точности
- Индикаторы риска

**Платный вариант:** STATSCORE TipsterAPI (€200-800/мес)
- Pre-match и live betting подсказки
- Математические модели прогнозов
- Контекстуальные инсайты с обоснованием
- 10+ видов спорта, 100+ рынков
- Миллионы инсайтов в год
- Идентификация value bets
- Оценка рисков

**Бесплатный вариант:** DIY (собственный расчет)
- Использовать The Odds API для коэффициентов
- Использовать TheSportsDB для исторических данных
- Построить простую модель прогноза:
  ```javascript
  const impliedProbability = 1 / odds;
  const estimatedProbability = calculateFromHistory(team, opponent);
  const valueScore = estimatedProbability - impliedProbability;
  
  if (valueScore > 0.1) {
    signal = "HIGH_VALUE_BET";
  }
  ```
- ❌ Нет профессиональных математических моделей
- ❌ Требует ручной разработки и поддержки
- ⚠️ Более низкая точность по сравнению с платными сервисами

## Бюджет API-запросов

### Ограничения бесплатных тарифов

**The Odds API:** 500 запросов/месяц
- 16 запросов/день
- Стратегия: Агрессивное кеширование, обновление каждые 6-12 часов

**TheSportsDB:** ~100 запросов/час
- 2,400 запросов/день
- Стратегия: Кешировать метаданные навсегда, счета на 5-10 минут

**API-Sports Free Tier:** 100 запросов/день
- Стратегия: Фокус только на 1-2 видах спорта

### Оптимизация запросов

**UnifiedSportsFeed:**
```
- Запрос расписаний: 1× в день (утром)
- Запрос live scores: 1× каждые 2-5 минут (только для live-матчей)
- Оценка: 50-200 запросов/день
```

**MultiSourceComparison:**
```
- Запрос при выборе матча: 1× на просмотр
- Кеш на 5 минут
- Оценка: 100-500 запросов/день
```

**OddsAggregator:**
```
- Запрос коэффициентов: 1× каждые 10-30 минут (pre-match)
- Запрос коэффициентов: 1× каждые 2-5 минут (live)
- Агрессивное кеширование
- Оценка: 50-300 запросов/день
```

**ValueRadar:**
```
- Расчет по требованию (нет API-вызовов при DIY)
- Или запрос подсказок: 1× на матч (при использовании TipsterAPI)
- Оценка: 0-100 запросов/день
```

**Всего примерно:** 200-1,100 запросов/день

**Бесплатный тариф поддерживает:** ~140 комбинированных запросов/день
- **Вывод:** Бесплатный тариф работает только для ограниченного демо/тестирования
